# CommercePulse v1.0.0

**Status: Prepared for release**

This document describes the release candidate. No Git tag or GitHub Release has been published.

## Highlights

- Commerce overview with a deterministic 30-day business snapshot
- Searchable, filterable, paginated order management and order details
- Product catalog, inventory health, stock thresholds, and product performance
- Customer value aggregation, behavioral segmentation, and order history
- Cross-domain analytics with period comparison and accessible charts
- Campaign portfolio with budgets, first-touch attribution, revenue, and ROAS
- Validated General, Notifications, and Appearance settings with local persistence

## Engineering

- Next.js App Router, React, strict TypeScript, and Tailwind CSS
- Feature-oriented architecture with Server Components by default
- TanStack Query caching over replaceable deterministic mock APIs
- URL-driven filters, pagination, periods, and navigation return state
- React Hook Form and Zod at form and persistence boundaries
- Responsive desktop, tablet, and mobile presentation
- Accessible dialogs, forms, tables, charts, focus states, and semantic landmarks

## Testing

- 32 Vitest files with 131 unit and component tests
- 9 Playwright files with 51 end-to-end tests
- 7 axe accessibility smoke tests included in the Playwright total

## Known Limitations

- Frontend-only architecture with in-browser mock APIs
- Deterministic fixture data anchored to August 28, 2026
- Settings persist only in the current browser through localStorage
- No authentication, real payment provider, database, or server-side persistence
